プライバシーポリシー

取得する情報

本ツールは Google の OAuth 認証により、運営者本人の YouTube アカウントについて次の権限のみを使用します。

  • youtube.upload：作成した動画のアップロードと公開設定
  • youtube.readonly：アップロード先チャンネル名の確認

利用目的

取得した権限は、運営者のチャンネルへ動画をアップロード・予約公開するためだけに使います。

保存と共有

認証トークンは運営者の PC 内にのみ保存し、外部のサーバーへ送信・共有・販売することはありません。第三者のユーザーデータは取得しません。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。YouTube API の利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

アクセスの取り消し

Google アカウントのセキュリティ設定 からいつでも取り消せます。
